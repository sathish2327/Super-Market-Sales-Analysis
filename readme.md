# Super Market Sales Analysis Dashboard

## 📊 Project Overview

This project is a **Super Market Sales Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard is designed to analyze supermarket sales performance and present important business metrics in an interactive and easy-to-understand format. It helps identify sales patterns, performance trends, and key areas of business performance.

## 🎯 Project Objectives

- Analyze overall supermarket sales performance.
- Monitor important sales KPIs.
- Identify sales trends and patterns.
- Compare performance across available categories and dimensions.
- Present business information through an interactive Power BI dashboard.
- Support data-driven business analysis and decision-making.

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query** – Data preparation and transformation
- **DAX** – Calculations and measures
- **Data Visualization** – Interactive charts, cards, tables, and dashboard elements

## 🚀 How to Use

1. Download or clone this repository.
2. Install **Microsoft Power BI Desktop**.
3. Open `super market sales (sathish).pbix`.
4. If Power BI asks for external data sources, follow the prompts to update/reconnect the data source.
5. Explore the dashboard using the available filters and visualizations.
